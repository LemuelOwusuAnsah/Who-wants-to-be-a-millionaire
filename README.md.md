# Wonders of the World Quiz · Millionaire Edition

A "Who Wants to Be a Millionaire?"-style quiz about the Wonders of the World.
Built with vanilla JavaScript, Bootstrap 5, and Font Awesome — fully modular and mobile-friendly.

## Features

- **Three difficulty levels** (Rookie, Explorer, Master) with 10 questions each
- **30-second timer** per question with visual warning
- **Two lifelines**: 50:50 (removes two wrong answers) and Skip
- **Score tracking** and progress bar
- **Responsive design** optimized for mobile, tablet, and desktop
- **Modular JavaScript** organized by concern
