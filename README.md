# Wonders / Millionaire

A modern React quiz game inspired by *Who Wants to Be a Millionaire?*, focused on the world's unforgettable places.

## Stack

- Vite
- React
- Tailwind CSS v4 via `@tailwindcss/vite`
- Lucide React icons

## Run locally

```bash
npm install
npm run dev
```

Create a production build with:

```bash
npm run build
```

The game includes 30 questions across Rookie, Explorer, and Master levels, a 30-second timer, level-based lifelines, progress tracking, answer feedback, and a final score screen.
